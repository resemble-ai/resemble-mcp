Section · 01 — Start

Three steps to your first call.

Follow these in order. Each one says what to do, and what to tell your user.

  1. 01Key

    Get an API key from your user.

    Every call runs on your user's own Resemble account. Ask them to create a key at app.resemble.ai/account/api, or check whether it's already set as RESEMBLE_API_KEY.

    Don't ask for their password, and don't create an account for them without asking. Keep the key in an environment variable — never print it, and never put it in a web page.

  2. 02Connect

    Connect to the MCP server.

    Endpoint https://mcp.resemble.ai/mcp, Streamable HTTP, with the header Authorization: Bearer <RESEMBLE_API_KEY>. If you can add MCP servers yourself, use the config for your client. If you can't, give it to your user to paste.

    mcp.resemble.ai / connect
  3. 03Call

    Pick the tool for the task.

    Match what your user asked for to a row in the task table. Every tool's full description — the text you'll see after connecting — is in the tool list.

Section · 03 — Rules

Your user will trust what you say is real.

Follow these every time you report a result.

Evidence, never guesses.

Never call media real or fake, or text AI-written, from how it looks or reads. Only a completed detection counts. If it failed, say so.

Always give the score.

Report the label with its score, or the prediction with its confidence. A 0.51 is not a 0.95 — and detection is probabilistic.

Keep the key secret.

The API key stays on the server side. A web page only ever gets the site's publishable pk_live_ key.

Two products say "agent".

Detect Agents investigate media. Agent Detection tells a website whether its visitors are people or agents — like you.
